<h1>💎 Тема: Flexbox — Создание макета профиля Instagram</h1>

Example: Необходимо сверстать страницу профиля Instagram, используя только Flexbox для построения структуры. Страница должна имитировать реальный профиль: аватар, имя пользователя, кнопки действий, статистику и сетку публикаций.
Основная цель — научиться выравнивать элементы по горизонтали и вертикали, распределять пространство, работать с вложенными flex-контейнерами и создавать адаптивную сетку.

Функциональные элементы для реализации:
<pre>
Шапка профиля:
~$Аватар слева
~$Блок информации справа
  
Блок информации должен содержать:
~$ Имя пользователя
~$ Кнопку «Редактировать профиль»
~$ Статистику (публикации, подписчики, подписки)
~$ Описание профиля

Сетка публикаций:
~$ Минимум 9 квадратных карточек
~$ Карточки должны располагаться в 3 колонки
~$ Использовать flex-wrap
</pre>
